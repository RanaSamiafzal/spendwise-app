# **App Name**: SpendWise

## Core Features:

- Transaction Input: Allow users to manually input income and expense transactions, assigning each to a specific category.
- Balance Overview: Display current balances of checking, savings and debts
- Visualized Spending: Visually represent spending patterns through charts and graphs (e.g., pie charts for category breakdown, line graphs for historical trends).
- Budget Setting: Set monthly budgets for each category and track progress against those goals.
- Expense Categorization: Categorize expenses based on user defined labels
- Spending Insights: Use an AI tool to analyze spending habits and identify potential savings opportunities.

## Style Guidelines:

- Primary color: Muted blue (#6699CC), evoking trust and security.
- Background color: Light gray (#F0F0F0), for a clean and unobtrusive backdrop.
- Accent color: Soft green (#99CC66), indicating positive budget performance and financial growth.
- Font pairing: 'Inter' (sans-serif) for body and 'PT Sans' (sans-serif) for headlines.
- Use simple, line-based icons to represent spending categories, for clarity and ease of recognition.
- Design a clean and intuitive dashboard layout, with clear sections for expense tracking, budget overview, and visual reports.
- Incorporate subtle animations to provide feedback and guide the user through key interactions, like adding a transaction or setting a budget.
